# 06 · Экраны: функциональная спецификация

Визуальные параметры (цвета, радиусы, тени, анимации) — в документе 04. Здесь — состав, поведение, данные и правила. Общий компонент коллекции игр — документ 07. Навигация и оболочка — документ 05.

---

## 1. Профиль (`/profile`)

### 1.1 Шапка
- Баннер (`profile.banner_image_id`, 16:5, fallback — градиент/материал дизайн-системы), аватар 96 px, имя, био (1–2 строки), «В приложении с <год первого `added_at`>».
- Бейдж уровня «Ур. 12 · Проходимец» с тонким прогресс-кольцом до следующего уровня; клик → модальный маршрут `/achievements` (§10). Скрывается только настройкой «Показывать достижения и уровень» (выкл.).
- Кнопка «Редактировать профиль» → диалог: имя, био, аватар (загрузка/обрезка 1:1), баннер (обрезка 16:5), **цель на год** (число игр, опционально), **топ-4 любимых игр** (поиск-пикер, drag для порядка).
- Плитки быстрой статистики (4): `Игр в библиотеке` · `Пройдено` · `Часов` · `Средняя оценка`. Каждая кликабельна: ведёт в библиотеку с соответствующим фильтром.

### 1.2 Кольца прогресса
Ряд из трёх колец (56 px): **Пройдено / всего** (без wishlist) · **100 % / пройдено** · **Цель года: пройдено в этом году / цель** (если цель не задана — кольцо «В этом году: N» без знаменателя, тонкая подсказка «Задайте цель»). Анимация заполнения при входе.

### 1.3 «Сейчас играю»
Горизонтальная лента карточек игр со статусом `playing`, отсортированных по `last_activity_at DESC`: обложка, название, часы, «последняя активность N дней назад», `resume_note` (1 строка), кнопки «+ время» (попап быстрого ввода) и «Пройдена ✓». Если пусто — «Ничего не проходите? Выберите игру из бэклога 🎲».

### 1.4 Топ-4 любимых
Четыре крупные обложки (Letterboxd «top four»); пустые слоты с плюсом. Клик по обложке → страница игры.

### 1.5 Статистика (секции сворачиваемые, порядок фиксирован)
1. **Статусы** — горизонтальный stacked-bar с легендой и процентами (все 7 статусов); hover — точное число; клик по сегменту → библиотека с фильтром.
2. **Пройдено по годам** — столбчатая диаграмма по годам завершения (`finished_at`), последние 8 лет + «раньше»; hover — число и суммарные часы; клик → библиотека «Пройдено» с фильтром по дате.
3. **Распределение оценок** — гистограмма 1–10 (показ звёздами ½…5), средняя оценка, число оценённых.
4. **Жанры** — топ-8 горизонтальных баров: число игр, доля, средняя моя оценка (второе значение справа); переключатель «по числу игр / по часам». Клик → библиотека с фильтром по жанру.
5. **Платформы** — аналогично, топ-6.
6. **Студии** — топ-6 разработчиков по числу пройденных: логотип, имя, N игр, средняя оценка.
7. **Часы** — всего, среднее на пройденную игру, топ-5 игр по часам (мини-список с обложками).
8. **Годы выпуска** — распределение библиотеки по декадам (мини-бар).
9. **Активность** — heatmap по дням за 12 месяцев по `play_sessions` с тумблером «Часы / Сессии» и выбором года, стрики (текущая и лучшая), клик по дню — сессии этого дня (ADR 0008).

Все агрегаты считаются модулем `stats` (документ 02 §5), кешируются, пересчитываются при записи.

### 1.6 Мои списки
Сетка карточек списков: мозаика из 4 обложек (или обложка/иконка списка), название, `N игр`, мини-кольцо прогресса; последняя карточка — «+ Новый список». Клик → список.

### 1.7 Последняя активность
Лента из `activity_log` (20 записей): иконка типа, текст «Elden Ring → Играю», «Оценил Hades II на 9», «Создан список Cozy игры», относительное время. «Показать всё» разворачивает до 100 с группировкой по дням.

### 1.8 Достижения (итерация 1, документ 09)
Секция «Достижения: 7 / 32 открыто» + прогресс-бар «5 320 XP · до 13 уровня 180 XP»; 6 последних открытых бейджей и 3 «ближайших» (с кольцом прогресса, например «Минус бэклог II — 38 / 50»); кнопка «Все достижения» → модальный маршрут `/achievements`. Достижения, зависящие от журнала сессий (стрик, сова), до итерации 2 показываются в общем списке серыми с пометкой «скоро» и в «ближайшие» не попадают.

## 2. Библиотека (`/library`)

Полностью описана в документе 07. Специфика:
- Подпункты сайдбара задают предустановленный статус (см. 07 §9).
- Заголовок: «Библиотека» / «Играю» / «Бэклог» / … ; подзаголовок «N игр · H ч».
- В «Бэклог» — переключатель группировки «по приоритету» (Высокий / Средний / Низкий / Без приоритета) и быстрый ввод приоритета на карточке (три точки).
- В «Пройдено» — группировка «по году завершения» включена по умолчанию.
- В «Хочу» — кнопка на карточке «Куплена → в бэклог» (меняет статус и ownership).
- Пустая библиотека: онбординг-плашка с тремя кнопками: «Добавить игру», «Добавить примерные данные», «Подключить облако» (если не подключено).

## 3. Списки

### 3.1 Все списки (`/lists`)
Сетка карточек (как 1.6), сортировка: по порядку сайдбара / названию / дате изменения / числу игр; поиск по названию; кнопка «Новый список».

### 3.2 Диалог создания/редактирования списка
Поля: **Название*** (уникальность не требуется), Описание (markdown, 500 симв.), Иконка (пикер из ~80 иконок набора дизайн-системы, поиск), Цвет (8 предустановленных + произвольный), Обложка (загрузка; если нет — мозаика первых 4 обложек), **Ранжированный** (показывать номера), Режим сортировки (ручной / по названию / по дате выхода / по дате добавления / по оценке), Закрепить в сайдбаре. Кнопки: Сохранить · Отмена · (в режиме редактирования) Удалить список.

### 3.3 Страница списка (`/lists/:id`)
- Шапка: обложка/иконка с цветом, название (inline-редактирование), описание (раскрывается), `N игр · H ч · годы`, кольцо прогресса, кнопки «Добавить игры», «⋯» (редактировать, дублировать, экспортировать в Markdown (итерация 2), удалить).
- Коллекция (документ 07) с ручным порядком по умолчанию: drag-n-drop карточек/строк; номер позиции; заметка к позиции (иконка на карточке; попап с текстом до 300 симв.).
- **Диалог «Добавить игры»**: поле поиска (по всей библиотеке и каталогу), результаты списком с чекбоксами, уже добавленные — отмечены и недоступны, кнопка «Добавить N» в подвале; по `Enter` при одном результате — добавить сразу. Также в диалоге — вкладка «Из фильтра»: применить фильтры библиотеки и добавить все совпадения (например, «все RPG 2015–2020»).
- Удаление списка: подтверждение с текстом «Игры останутся в библиотеке». Удаление игры из списка — тост с «Отменить».
- Игра, которой нет в библиотеке (только в каталоге), в списке показывается с приглушённой обложкой и бейджем «не в библиотеке»; на hover — «Добавить в бэклог».

## 4. Серии

### 4.1 Все серии (`/series`)
Сетка карточек: обложка серии (или мозаика), название, `N игр`, годы «2009–2024», мини-кольцо, разработчик (если у ≥ 70 % игр один). Сортировка: название / число игр / последняя игра / прогресс. Поиск. Кнопка «Новая серия» → форма каталога.

### 4.2 Страница серии (`/series/:id`)
- Шапка: баннер (или размытая обложка первой игры), обложка серии, название, описание, `N игр · пройдено X · H ч`, кольцо прогресса, кнопки «Добавить игру в серию», «Редактировать» (форма каталога), «⋯» (автонумерация по дате выхода, удалить серию).
- Под-серии (если есть `parent_series_id = this`): чипы с названиями и счётчиками; клик — переход. Игры под-серий на странице родителя показываются в отдельных секциях (по под-серии), с собственной нумерацией, если включено «показывать под-серии».
- **Порядок игр**: вид «список» по умолчанию (номер, обложка, название, год, платформы, статус, моя оценка, часы). Drag-handle слева; перетаскивание меняет `position`, номера пересчитываются анимированно (FLIP). Работает и в сетке (карточки с номерами). Доступно с клавиатуры: фокус на handle, `Space` — захват, `↑↓` — перемещение, `Space` — отпустить, `Esc` — отмена. Ввод номера вручную: клик по номеру → поле → `Enter`.
- DLC/дополнения показываются вложенно под родительской игрой (отступ, меньшая карточка), в нумерации не участвуют; переключатель «Показывать DLC».
- Метка позиции (`label`, напр. «Спин-офф») — редактируется в контекстном меню элемента; показывается бейджем.
- «Добавить игру в серию» — диалог поиска по каталогу с чекбоксами; новые игры добавляются в конец.
- «Автонумерация по дате выхода» — перенумеровывает по `release_date ASC`, подтверждение, отмена через тост.
- Статистика внизу: суммарные часы, средняя моя оценка, разброс metacritic, таймлайн выпуска (мини-график по годам с точками-обложками, hover — название).

## 5. Студии и издатели

### 5.1 Индекс (`/companies`)
Вкладки: **Все · Разработчики · Издатели**. Сетка карточек: логотип (или инициалы на `dominant_color`), название, флаг страны, `N игр в каталоге · M у меня`, мини-кольцо «пройдено из моих». Сортировка: название / число игр / страна / год основания. Фильтр по стране (комбобокс) и по букве (алфавитный указатель справа). Поиск. «Добавить студию».

### 5.2 Страница компании (`/companies/:id`)
- Шапка: баннер, логотип, название, роль-бейджи («Разработчик», «Издатель»), страна с флагом и город, «Основана 1986 · Закрыта —», ссылка на сайт, «Часть: Kadokawa» (ссылка на родителя), описание (раскрывающееся). Кнопки: «Редактировать», «⋯» (удалить — только если нет игр).
- Плитки: `Игр` · `Серий` · `Пройдено у меня` (кольцо) · `Средняя моя оценка`.
- Вкладки:
  - **Игры** — коллекция (документ 07) с предустановленным фильтром по компании; чипы роли: Разработала / Издала / Портировала / Помогала (по `game_companies.role`); сортировка по дате выхода по умолчанию (DESC), группировка «по серии» одной кнопкой.
  - **Серии** — карточки серий, в которых у компании ≥ 1 игра; на карточке — «3 из 5 игр серии».
  - **Дочерние компании** — если есть `parent_company_id = this`: карточки студий (для издателей типа Xbox Game Studios, Sony Interactive). Вкладка скрыта, если пусто.
- Издатель и студия — одна сущность с флагами ролей; страница одна и та же, набор вкладок один.

## 6. Страница игры (`/games/:id`)

### 6.1 Шапка (hero)
- Фон: `backdrop_image` с затемнением снизу; если нет — размытая обложка + `dominant_color`. Высота 240–320 px в зависимости от высоты окна.
- Обложка 3:4 (180 px шириной) наезжает на фон; клик — просмотр в полный размер; hover — «Сменить обложку» (открывает форму каталога на поле обложки).
- Название (H1), альтернативные названия мелко, бейдж категории (для DLC — «DLC к <родитель>» со ссылкой), дата выхода с учётом точности («24 фев 2022», «2026», «TBA»), статус релиза («Ранний доступ»).
- Строка связей: **Разработчик** (ссылки, несколько через запятую) · **Издатель** · **Серия** «Souls · 6 из 7» (ссылка на серию) · страна студии с флагом.
- Чипы: жанры (основной первым), режимы, платформы. Клик по чипу → библиотека с фильтром.
- Блок оценок справа: **Metacritic** (цветная плашка 0–100: ≥75 зелёный, 50–74 жёлтый, <50 красный, ссылка), **OpenCritic**, **IGDB** (будущее), **Моя оценка** крупно.
- Времена прохождения (если заданы): «Основной сюжет 58 ч · С доп. 101 ч · 100 % 133 ч» и рядом «У меня: 61 ч» с мини-баром соотношения.

### 6.2 Панель пользователя (sticky справа, 320 px; на узком окне — под шапкой)
Все поля — **автосохранение** (документ 05 §7).
1. **Статус** — кнопка-селектор во всю ширину с цветом и иконкой статуса; клик → меню из 7 пунктов с описанием («Отложена — вернусь позже»), горячие клавиши `1–7`. Смена статуса анимирует цвет кнопки. Правила автозаполнения дат — документ 02 §4.
2. **Оценка** — 5 звёзд с половинками (шкала 1–10): hover-превью, клик — установить, клик по текущему — снять; подпись словом («9 — Великолепно»: 1–2 Ужасно, 3–4 Плохо, 5 Так себе, 6 Нормально, 7 Хорошо, 8 Очень хорошо, 9 Великолепно, 10 Шедевр). Недоступна при статусах `wishlist`/`backlog` (tooltip «Сначала поиграйте»).
3. **Флаги**: `100 % / платина` (только completed/played), `Избранное` ♥.
4. **Время** — поле `ч` + `мин`, кнопки `+15м` `+1ч` `+2ч` и переключатель «Считать по журналу»; при `playtime_mode = sessions` вместо полей — итог и кнопка «Добавить сессию» (ADR 0008).
5. **Даты**: Начал · Закончил — date-picker, кнопка «сегодня», очистка. Валидация: закончил ≥ начал.
6. **Платформа** (комбобокс из платформ игры + «другая…»).
7. **Владение**: селектор (Цифра / Физическая / Подписка / Пиратка / Нет / Продана) + магазин (иконки Steam/Epic/GOG/PSN/Xbox/Nintendo/…) — для «Цифра»; для подписки — название сервиса; для «Пиратка» магазин не показывается.
8. **Приоритет** (только для backlog): три сегмента.
9. **Списки**: чипы текущих списков (крестик — убрать) + «+ В список» (поповер с поиском и «Создать список»).
10. **Теги**: чипы + ввод с автодополнением (создание на лету).
11. **Где остановился** (`resume_note`) — однострочное поле (200 симв.).
12. **Заметки** — markdown-редактор (свернут до 3 строк, разворачивается), приватные.
13. **Отзыв** — markdown, чекбокс «содержит спойлеры» (в списках отзыв скрывается под плашкой).
14. Низ панели: «Убрать из библиотеки» (текстовая кнопка, тост с отменой; каталожная запись остаётся).

### 6.3 Основная колонка
1. **Описание** (`summary`) — до 6 строк, «Читать дальше». **Сюжет** (`storyline`) — отдельный раскрывающийся блок с пометкой «может содержать спойлеры».
2. **В серии** — горизонтальная лента обложек серии с номерами; текущая выделена; статусы — точками; клик — переход (shared-element). Кнопка «Открыть серию».
3. **Дополнения (DLC)** — список дочерних игр (`parent_game_id = this`): обложка-миниатюра, название, год, **собственный статус** (мини-селектор, если DLC есть в библиотеке; иначе кнопка «В бэклог»). Итог: «Пройдено 1 из 2».
4. **Издания и связанные** — ремейки/ремастеры/порты этой игры (`category ∈ remake, remaster, port` с `parent_game_id = this`) чипами.
5. **От того же разработчика** — до 6 обложек (исключая текущую), «Все игры студии →».
6. **История** — таймлайн по `activity_log` для этой игры (добавлена, статус → …, оценка, время). Прохождения и журнал сессий — отдельными секциями выше (ADR 0008).
7. **Ссылки**: сайт, Metacritic, (будущее) Steam/IGDB.
8. Подвал: «Редактировать в каталоге» (`E`), «Изменено <дата>», источник данных («вручную»).

### 6.4 Поведение
- Экран открывается за один запрос (`getGamePage(id)` возвращает всё, включая серию, DLC, компании).
- Все изменения пользовательских полей → `activity_log`.
- Если игры нет в библиотеке (открыта из каталога/поиска) — вместо панели пользователя большая кнопка «Добавить в библиотеку» с селектором статуса (по умолчанию «В бэклог»); после клика панель появляется с анимацией.

## 7. Модерация / добавление контента (`/catalog`)

### 7.1 Хаб (`/catalog`)
Плитки быстрых действий: **Игра** · **Студия / издатель** · **Серия** · **Жанр** · **Платформа** · **Тег**. Ниже — счётчики каталога и «Недавно добавлено» (10 сущностей). Ссылки на таблицы сущностей.

### 7.2 Таблицы сущностей (`/catalog/:entity`)
Таблица с поиском и сортировкой: для игр — обложка, название, год, разработчик, категория, **заполненность** (процент заполненных ключевых полей: обложка, дата, описание, жанры, разработчик, издатель, платформы, серия, metacritic), «в библиотеке» (да/нет), изменено. Действия: редактировать, дублировать (для изданий), удалить. Мультивыбор для массовых действий: назначить жанр/платформу/серию, удалить.
Для компаний — логотип, название, роли, страна, N игр; для серий — обложка, название, N игр; для жанров/платформ/тегов — имя, N игр, «объединить с…» (слить дубликаты: все связи переносятся, подтверждение).

### 7.3 Форма игры (`/catalog/games/new`, `/catalog/games/:id/edit`)
Верх формы — панель **«Заполнить из источника»**: селектор провайдера (IGDB · Steam · …) + поле поиска + кнопка «Найти». В итерации 1 панель отрисована, но **отключена** с tooltip «Появится в следующей версии»; структура формы рассчитана на подстановку значений в поля с подсветкой «изменено импортом» и возможностью отменить по полю (документ 08).

Поля (группами, с валидацией):
- **Основное**: Название* (при вводе — «Похожие в каталоге: …» для защиты от дублей); Альтернативные названия (чипы); Название для сортировки (авто, редактируемое); Slug (авто, только чтение, кнопка «пересоздать»); Категория (селектор) → при `dlc/expansion/remake/remaster/port/standalone_expansion` появляется поле **Родительская игра** (поиск).
- **Выпуск**: Дата выхода с переключателем точности (Полная дата / Месяц / Год / TBA) — компонент подстраивает поле; Статус релиза; Возрастной рейтинг (текст с подсказками PEGI/ESRB).
- **Описание**: Краткое (textarea, счётчик до 1000), Сюжет (textarea).
- **Изображения**: Обложка (зона drop / кнопка «Выбрать файл» / «Вставить из буфера» `Ctrl+V` / поле URL → скачивание backend’ом); после выбора — **кроппер 3:4** с зумом; Фон 16:9 с кроппером; Логотип (без кроппера, PNG с прозрачностью сохраняется как PNG). Показ размера/веса после конвертации. Кнопка «Убрать».
- **Связи**: Разработчики (мульти-комбобокс с поиском, пункт «Создать студию «…»» открывает мини-форму в поповере — имя, страна, роль), Издатели (аналогично), Серия (комбобокс + опциональный номер позиции; «Создать серию»), Жанры (мультивыбор, звёздочкой отмечается основной), Режимы, Платформы (сгруппированы по семейству; кнопки «все PC», «все PlayStation»).
- **Оценки и время**: Metacritic (0–100) + URL, OpenCritic, HLTB: Основной / С доп. / 100 % — ввод в часах и минутах.
- **Ссылки**: Сайт.
- **Библиотека** (только при создании): чекбокс «Сразу добавить в мою библиотеку» (включён) + статус (по умолчанию «В бэклог»).

Подвал (sticky): «Сохранить» (`Ctrl+S`), «Сохранить и добавить ещё», «Отмена». После сохранения — тост и переход на страницу игры (или очистка формы при «добавить ещё»; связи «разработчик/серия/платформы» можно «закрепить» булавкой, чтобы они остались для следующей игры).
Правки любого поля записывают `field_provenance(provider='manual', locked=1)`.

### 7.4 Форма компании
Название*, Название для сортировки, Slug, Роли (Разработчик / Издатель — чекбоксы, хотя бы одна), Страна (комбобокс с флагами и поиском по русскому/английскому названию), Город, Год основания, Год закрытия, Родительская компания (поиск), Описание, Сайт, Логотип (квадрат, PNG/WebP), Баннер (16:5).
Удаление: если есть связанные игры — блокируется с сообщением «У компании N игр. Сначала переназначьте их» и ссылкой на таблицу игр с фильтром по компании; «Объединить с другой компанией» — переносит все связи.

### 7.5 Форма серии
Название*, Тип (Серия / Франшиза), Название для сортировки, Slug, Родительская серия, Описание, Обложка (3:4), Баннер. Состав серии редактируется на странице серии.
Удаление: разрешено; связи `series_games` удаляются; подтверждение с числом игр.

### 7.6 Формы жанра / платформы / тега
Жанр: Название*, Slug, Описание, Цвет. Платформа: Название*, Короткое имя*, Семейство*, Порядок. Тег: Название*, Цвет. Удаление — с подтверждением, связи снимаются. Операция «Объединить» для дублей.

### 7.7 Общие правила форм
- Валидация при вводе и при сохранении; ошибки под полем; первое невалидное поле получает фокус.
- Уход со страницы с несохранёнными изменениями — диалог.
- Изображения: принимаются PNG/JPEG/WebP/GIF (первый кадр)/BMP до 25 МБ; конвертация в WebP q85 (логотипы с альфа-каналом — PNG), вычисление `dominant_color`, sha256 (дедупликация: одинаковый файл не хранится дважды).
- Автосохранение черновика формы в памяти при навигации внутри приложения (возврат «назад» восстанавливает введённое).

## 9. Поиск (`/search?q=`)
Страница полных результатов из палитры: группы Игры / Серии / Студии / Списки, коллекция игр (документ 07) без панели фильтров, с сортировкой по релевантности. Игры не из библиотеки показываются с кнопкой «В бэклог».

## 10. Достижения (`/achievements`, итерация 1)
Модальное окно поверх текущего экрана: заголовок «Уровень 12 · 5 320 XP · до 13 уровня 180 XP» с прогресс-баром; сетка бейджей (открытые цветные, закрытые серые с прогрессом «7 / 10»); фильтр «все / открытые / близкие»; клик по бейджу — карточка с условием и датой. Детали — документ 09.
