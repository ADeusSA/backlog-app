# 09 · Уровень и достижения (итерация 1)

Входит в итерацию 1 (решение пользователя 2026-09-07). Схема — `user_achievements`, `profile.xp`, `activity_log` (документ 02); UI — бейдж уровня в профиле и сайдбаре, секция профиля 1.8, модальный маршрут `/achievements` (документ 06 §10). Достижения, которым нужен журнал сессий (`streak`, `night_owl`), активируются в итерации 2 вместе с сессиями; до этого они присутствуют в каталоге как «скоро» (серые, без прогресса, XP не дают). Идеи основаны на исследовании `docs/research/01-analogs.md` §C.

## 1. Принципы
- Достижения считаются **детерминированно из данных** (`user_game`, `play_sessions`, `lists`, `activity_log`), а не хранятся как «факты». `user_achievements` — кеш прогресса и даты открытия; его можно пересчитать с нуля командой «Пересчитать достижения».
- Открытие достижения — событие `activity_log(type = achievement_unlocked)` + тост с анимацией бейджа (единственное место с «конфетти»: 600 мс, частицы цветов `--accent`/`--success`, ≤ 40 частиц).
- Ничего не «наказывает»: достижения не теряются при удалении игр (дата открытия сохраняется, прогресс может уменьшиться).
- Всё локально; никаких серверных сравнений.

## 2. Опыт и уровень
```
XP = 10 × пройдено
   + 15 × mastered (100 %)
   + min(часы_по_игре, 100) суммарно по играм       // кап 100 XP на игру
   + 3 × отзыв (≥ 200 символов)
   + 20 × каждый открытый уровень достижения
Уровень = floor(XP / 500) + 1         // линейно, предсказуемо
```
Титулы уровней (показываются в профиле рядом с числом): 1 «Новичок», 5 «Коллекционер», 10 «Проходимец», 15 «Ветеран», 20 «Куратор», 30 «Легенда бэклога», 50 «Точка невозврата». Косметика за уровни (итерация 3): рамки аватара, варианты bloom-палитры профиля.

## 3. Каталог достижений

| key | Название | Уровни / условие | Источник данных |
|---|---|---|---|
| `first_blood` | Первая кровь | первая игра со статусом completed | user_game |
| `backlog_minus` | Минус бэклог | пройдено 10 / 50 / 100 / 250 / 500 / 1000 | user_game |
| `platinum` | Платиновый | mastered 1 / 5 / 25 / 100 | user_game |
| `marathon` | Марафонец | 100 / 500 / 2000 / 10000 часов суммарно | user_game.playtime |
| `streak` | Стрик | 7 / 30 / 100 дней подряд с сессией | play_sessions — **итерация 2** |
| `retro` | Ретроман | 10 / 30 пройденных игр с release_year < 2000 | user_game + games |
| `series_complete:<series_id>` | Серийный | пройдены все основные игры серии (≥ 3 игр) | series_games |
| `genre_gourmet:<genre_id>` | Жанровый гурман | 5 / 15 / 40 пройденных в жанре | game_genres |
| `year_balance` | Годовой баланс | за календарный год пройдено ≥ добавлено | user_game.added_at / finished_at |
| `excavator` | Разгребатель | пройдена игра, лежавшая в бэклоге > 2 лет | added_at → finished_at |
| `speedrunner` | Скороход | 5 игр пройдены быстрее `hltb_main_min` | playtime vs hltb |
| `multiplatform` | Мультиплатформенник | прохождения на 3 / 6 / 10 разных платформах | user_game.platform_id |
| `critic` | Критик | 10 / 50 / 200 отзывов | user_game.review |
| `curator` | Куратор | 5 списков или один список из 50+ игр | lists |
| `fair_judge` | Честный судья | 100 оценок и ≥ 6 разных значений шкалы | user_game.rating |
| `night_owl` | Сова | 20 сессий, начатых после 23:00 (если время сессий ведётся) | play_sessions — **итерация 2** |
| `comeback` | Возвращение | пройдена игра, побывавшая в «Отложена» | activity_log |

Определения — в коде (`src/features/achievements/definitions.ts`): `{ key, title, description, levels: [{ threshold, xp }], compute(ctx) }`. Параметризованные (`series_complete:*`, `genre_gourmet:*`) генерируются по данным.

## 4. UI
- **Профиль**: бейдж «Ур. 12» у имени; секция «Достижения: 7 / 32» с последними 6 бейджами и прогресс-баром до следующего уровня.
- **Модальный маршрут `/achievements`**: шапка (уровень, XP, до следующего), фильтры «все / открытые / близко», сетка бейджей 96 px: открытые — цветные (иконка Lucide на подложке `--accent-soft`, для платиновых — `--success-soft`), закрытые — серые с кольцом прогресса; клик — карточка с условием, прогрессом «7 / 10», датой открытия, ссылкой на игры, которые «засчитались».
- **Тост открытия**: слева бейдж с анимацией появления (scale .6→1, `emphasized` 400 мс), «Достижение открыто: Минус бэклог II».
- Настройка «Показывать достижения» (можно выключить всю геймификацию).

## 5. Производительность
Пересчёт — при записи в затронутые таблицы, инкрементально по ключам, зависящим от изменённой сущности; полный пересчёт ≤ 300 мс на 2000 игр; выполняется в backend после коммита транзакции, результат — событие в UI.
