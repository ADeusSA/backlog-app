# 05 · Оболочка приложения и навигация

## 1. Окно

- Собственный заголовок окна: `titleBarStyle: 'hidden'` + Window Controls Overlay (документ 01 §8). Содержимое заголовка рисует приложение; системные кнопки «свернуть / развернуть / закрыть» — нативные (снап-раскладки Windows 11, double-click = развернуть). Перетаскивание — через `-webkit-app-region: drag` на области заголовка и `no-drag` на контролах; ширина области под системные кнопки учитывается через `env(titlebar-area-width)`.
- Минимальный размер 1024 × 680. Размер, позиция и состояние «развёрнуто» запоминаются в локальном `settings.json` и восстанавливаются с проверкой, что монитор существует.
- Поддержка масштабирования DPI (125 / 150 / 175 %) — все размеры в `rem`/`px` с учётом devicePixelRatio, картинки с `srcset`-подобной логикой (обложки не растягиваются выше исходного размера).
- Фон окна — сплошной `--bg-0` (#0B0D14, дизайн-система Aurora); `backgroundColor` окна задан тем же цветом, окно показывается по `ready-to-show`, чтобы не было светлой вспышки при старте.
- Закрытие окна: если идёт синхронизация — окно скрывается, показывается маленький прогресс-тост «Сохраняем в облако…», приложение закрывается по завершении (таймаут 30 с, потом закрыть с записью в лог).

## 2. Заголовок окна (titlebar, 44 px)

Слева → направо:

1. Логотип приложения (кликабельный → профиль).
2. **Назад / Вперёд** — кнопки истории; неактивная — приглушена. Долгое нажатие или ПКМ → выпадающий список последних 10 записей истории в этом направлении (как в браузере).
3. **Хлебные крошки** (см. §4).
4. Растяжка (drag region).
5. **Глобальный поиск** — поле-кнопка «Поиск игр, серий, студий… `Ctrl K`» открывает командную палитру (§6).
6. **Индикатор синхронизации** — иконка облака: состояния `synced` (галочка), `syncing` (анимация), `pending` (точка: есть несохранённые в облако изменения), `offline`, `error` (красная). Клик → поповер: «Последняя выгрузка 12:31 · Последняя загрузка 09:02 · Синхронизировать сейчас · Открыть настройки». Если облако не подключено — иконка серая, клик ведёт к подключению.
7. Системные кнопки окна (нативные, Window Controls Overlay; цвет символов `--text-2`, фон `--bg-0`).

## 3. Боковая панель (sidebar)

- Ширина 240 px; сворачивается до рельсы 64 px (только иконки, подписи — в tooltip) кнопкой в низу панели или `Ctrl+B`; состояние запоминается. В варианте дизайна D (Aurora) рельса — режим по умолчанию.
- Секции (сверху вниз):
  1. **Карточка профиля**: аватар, имя, «Ур. N», маленькое кольцо прогресса. Клик → `/profile`; клик по уровню → `/achievements`.
  2. **Библиотека**: `Все` · `Играю` · `Бэклог` · `Пройдено` · `Отложено` · `Брошено` · `Хочу` — каждая строка со счётчиком; счётчики обновляются реактивно при любой записи.
  3. **Списки**: закреплённые (`is_pinned`) пользовательские списки с иконкой/цветом и счётчиком; перетаскиванием меняется порядок (`sort_order`); внизу `+ Новый список` (открывает диалог создания) и «Все списки» (если закреплены не все).
  4. **Каталог**: `Серии` · `Студии и издатели` · `Жанры и теги`.
  5. Низ панели: `Добавить контент` (акцентная кнопка), `Настройки`, кнопка сворачивания.
- Активный пункт подсвечен; hover — фон; клавиатурная навигация стрелками внутри панели.
- Секции сворачиваются (шеврон), состояние запоминается.
- Drag-n-drop **игры на пункт панели**: карточку игры можно перетащить на список в сайдбаре (добавить) или на статус («Играю» — сменить статус). Подсветка цели при наведении.

## 4. Модель навигации

### 4.1 История
- История переходов — стек как в браузере (роутер с memory/hash history). `Назад` (`Alt+←`, кнопка мыши 4 / XButton1, `Backspace` вне полей ввода — опционально, по умолчанию выключено), `Вперёд` (`Alt+→`, XButton2).
- Каждая запись истории хранит: маршрут + search-параметры (фильтры, сортировка, вид, seed случайной сортировки) + позицию скролла + раскрытые секции. Возврат восстанавливает всё.
- Переход на тот же маршрут с другими фильтрами — **replace**, а не push (чтобы кнопка «назад» не листала каждое движение слайдера); исключение — смена scope (другой список/статус) — push.

### 4.2 Хлебные крошки
- Отражают **логическое положение**, а не историю: `Библиотека › Бэклог`, `Списки › Cozy игры`, `Серии › Souls › Elden Ring`, `Студии › FromSoftware`, `Каталог › Игры › Новая игра`.
- Для страницы игры первый сегмент зависит от того, откуда пришли (контекст передаётся в состоянии маршрута): из списка — `Списки › Cozy игры › Elden Ring`; из серии — `Серии › Souls › Elden Ring`; по умолчанию — `Библиотека › Elden Ring`.
- Каждый сегмент кликабелен. Между сегментами — шеврон; **клик по шеврону** открывает выпадающий список «соседей» следующего уровня (как адресная строка Проводника): после `Списки ›` — все списки; после `Серии ›` — все серии; после `Souls ›` — игры серии по порядку. Это быстрый способ «перепрыгнуть» на соседнюю сущность.
- На узком окне средние сегменты сворачиваются в `…` с выпадающим списком.

### 4.4 Переходы между экранами (анимация)
- Смена страницы: контентная область — cross-fade 160 мс + сдвиг 12 px (вперёд — из правого края, назад — из левого); сайдбар и titlebar статичны.
- Открытие страницы игры из карточки — **shared-element**: обложка карточки «перелетает» на своё место в шапке игры (через `layoutId`/View Transitions), остальной контент проявляется с задержкой 80 мс. При `prefers-reduced-motion` — только fade.
- Скролл-позиция восстанавливается до анимации, чтобы не было «прыжка».

## 5. Горячие клавиши (глобальные)

| Клавиши | Действие |
|---|---|
| `Ctrl+K` | Командная палитра / поиск |
| `Ctrl+B` | Свернуть/развернуть сайдбар |
| `Ctrl+N` | Новая игра (каталог) |
| `Ctrl+Shift+N` | Новый список |
| `Ctrl+F` | Поиск внутри текущей коллекции |
| `Ctrl+Shift+F` | Показать/скрыть панель фильтров |
| `Ctrl+1…7` | Библиотека: Все / Играю / Бэклог / Пройдено / Отложено / Брошено / Хочу |
| `Ctrl+,` | Настройки |
| `Alt+←` / `Alt+→` | Назад / Вперёд |
| `Alt+↑` | На уровень выше по крошкам |
| `Ctrl+S` | Сохранить (в формах модерации) |
| `Ctrl+Shift+S` | Синхронизировать сейчас |
| `Esc` | Закрыть попап / снять выделение / выйти из поиска |
| `?` | Показать шпаргалку горячих клавиш |
| На странице игры: `S` статус, `R` оценка (фокус на звёзды), `T` время, `L` в список, `F` избранное, `E` редактировать | |

Все сочетания редактируются в настройках (итерация 2); в итерации 1 — фиксированы, но вынесены в одну таблицу в коде.

## 6. Командная палитра (`Ctrl+K`)

- Модальное поле ввода по центру сверху; ниже — результаты в группах: **Игры** (обложка-миниатюра, название, год, статус-точка), **Серии**, **Студии и издатели**, **Списки**, **Команды**.
- Поиск: FTS5 по `search_index` (префиксный, с транслитерацией «елден» ↔ «elden» через таблицу замен) + fuzzy-ранжирование в UI; результаты обновляются на каждый ввод (дебаунс 60 мс), максимум 8 на группу; «Показать все результаты →» ведёт на `/search`.
- Пустой ввод показывает: «Недавние» (последние 8 открытых сущностей) и «Быстрые команды».
- Команды: `Добавить игру`, `Добавить студию`, `Добавить серию`, `Новый список`, `Открыть настройки`, `Переключить тему`, `Синхронизировать сейчас`, `Случайная игра из бэклога`, `Свернуть сайдбар`, `Сетка / Список`. Команды ищутся по префиксу `>` либо просто по тексту.
- Клавиатура: `↑↓` навигация, `Enter` открыть, `Ctrl+Enter` открыть в… (для игры — сразу меню статуса), `Tab` переключение групп.
- Действия над игрой прямо из палитры: при выделенной игре `→` открывает подменю (сменить статус, добавить в список, оценить) — не покидая палитру.

## 7. Обратная связь и системные элементы

- **Тосты** — правый нижний угол, стек до 3, авто-скрытие 4 с; для разрушительных действий — кнопка «Отменить» (5 с, отмена реально откатывает транзакцию по сохранённому снимку данных).
- **Подтверждения** — модальный диалог только для необратимых операций (удаление из каталога, удаление списка, сброс данных). Удаление игры из библиотеки/списка — без диалога, но с тостом «Отменить».
- **Скелетоны** при загрузке > 120 мс; спиннеры не используются, кроме индикатора синхронизации и кнопок с длительными операциями (сохранение картинки, синк).
- **Ошибки**: глобальный error boundary с текстом «Что-то пошло не так», кнопками «Перезагрузить экран», «Открыть журнал»; все ошибки пишутся в `logs/app.log`.
- **Пустые состояния**: иллюстрация (SVG в стиле дизайн-системы), заголовок, одна кнопка действия.
- **Автосохранение** пользовательских данных (статус, оценка, время, заметки) — без кнопки «Сохранить»: изменения пишутся через 400 мс после последнего ввода, индикатор «Сохранено ✓» рядом с полем. Формы каталога (модерация) — с явной кнопкой «Сохранить» и защитой от потери изменений при уходе (диалог «Есть несохранённые изменения»).
- **Локализация**: все строки — через словарь (`ru` основной, `en` полный). Даты/числа — `Intl` с локалью интерфейса. Часы отображаются как `61 ч 20 мин`, в компакте `61 ч`; ≥ 1000 — `1 240 ч`.
- **Доступность**: фокус видим всегда; все интерактивные элементы имеют роли/имена; контраст текста ≥ 4.5:1 в обеих темах; анимации отключаются при `prefers-reduced-motion` или в настройках.

## 8. Первый запуск (`/welcome`)

Три шага в одном окне с индикатором прогресса:
1. **Где хранить данные** — по умолчанию `<папка exe>/data` (portable). Кнопка «Выбрать другую папку». Если в выбранной папке уже есть `backlog.db` — «Найдена база от <дата>, использовать её».
2. **Профиль** — имя, аватар (опционально).
3. **Google** — одна крупная кнопка **«Войти через Google»** и короткое пояснение «Ваши данные будут храниться в папке Backlog на вашем Google Диске и синхронизироваться между вашими компьютерами». Нажатие открывает системный браузер, пользователь выбирает аккаунт и подтверждает доступ; приложение само создаёт папку и включает синхронизацию. Никаких ключей, полей и «продвинутых настроек» — приложение можно передать другому человеку как есть (документ 03 §11). Вторичная ссылка «Позже, без облака». Если вход выполнен и на Диске уже есть база — предложить «Загрузить из облака» vs «Оставить локальную» (с датами и размером обеих); если локальная база пустая — загрузить без вопросов.
Финал: чекбокс «Добавить примерные данные (12 игр, 3 студии, 2 серии) — можно удалить позже» → кнопка «Начать». Мастер можно закрыть крестиком — тогда применяются значения по умолчанию.

## 9. Критерии приёмки

1. Кнопки/клавиши назад-вперёд работают во всех экранах, восстанавливая фильтры и скролл; список истории при долгом нажатии показывает заголовки страниц.
2. Хлебные крошки корректно отражают контекст перехода на страницу игры из списка, серии, студии, поиска.
3. Выпадающие «соседи» по шеврону работают для списков, серий, студий, игр серии.
4. `Ctrl+K` находит игру по части названия и по альтернативному названию ≤ 100 мс на 2 000 игр; выполняет команды.
5. Свёрнутый сайдбар сохраняет функциональность (tooltip, drag-n-drop на пункты).
6. Приложение корректно закрывается во время синхронизации без потери данных.
