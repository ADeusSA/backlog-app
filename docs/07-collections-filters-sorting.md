# 07 · Коллекция игр: виды, фильтры, сортировка, прогресс

Единый компонент **`GameCollectionView`** используется везде, где показывается набор игр: библиотека (бэклог и разрезы по статусу), пользовательский список, серия, студия/издатель, результаты поиска, каталог на странице модерации. Поведение ниже обязательно для всех этих мест; отличия описаны в §9.

| Элемент | Поведение |

| Подзаголовок | `N игр · H ч` + контекст (для списка — описание; для серии — годы «2009–2024»; для студии — страна, основана) |
| **Кольцо прогресса** | см. §6 |
| Переключатель вида | сегмент «сетка / список», запоминается на scope |
| Сортировка | dropdown: поле + направление (иконка стрелки, клик меняет направление); см. §5 |

| Пресеты фильтров | чипы под заголовком; активный подсвечен; «+» сохраняет текущее состояние как новый пресет; ПКМ/долгое нажатие — переименовать/удалить |
| Поиск внутри коллекции | поле появляется по `Ctrl+F` или кнопке 🔍 в заголовке, фильтрует по названию мгновенно (без запроса к БД — по загруженным элементам, если их ≤ 2000; иначе — запрос) |

## 3. Вид «Сетка»

Карточка (размер M: обложка 3:4 при ширине колонки ~150–180 px; сетка `repeat(auto-fill, minmax(Wpx, 1fr))`, W = 120 / 160 / 210 для S/M/L):

- Обложка; при отсутствии — плейсхолдер: заливка `dominant_color` или нейтральный фон + первые буквы названия.
- Оверлей статуса: бейдж в левом верхнем углу (цвет статуса), для `completed` — галочка; для `is_mastered` — иконка трофея; для `is_favorite` — сердечко в правом верхнем углу.
- Подпись: название (1 строка, ellipsis, полный текст в tooltip), вторая строка — настраиваемое поле: **год · часы** по умолчанию; в настройках вида можно выбрать: разработчик / жанр / моя оценка / metacritic / платформа / дата добавления (идея GOG Galaxy — одно доп. поле).
- Для ранжированных списков и серий — **номер позиции** крупно в левом нижнем углу обложки.
- **Hover**: карточка приподнимается (см. дизайн-систему), появляется полоса быстрых действий: «Сменить статус» (меню), «Записать время», «В список», «Оценить» (звёзды inline). Действия не открывают страницу игры.
- **Клик** — открыть страницу игры. `Ctrl+клик` — выделить (мультивыбор). `Shift+клик` — диапазон.
- **Контекстное меню** (ПКМ): Открыть · Сменить статус ▸ · Оценить ▸ · Добавить в список ▸ · Записать время · Избранное · Редактировать (модерация) · Убрать из списка (в списке) · Убрать из библиотеки.
- **Мультивыбор**: панель действий снизу («Выбрано 5: статус ▾, в список ▾, теги ▾, убрать»); `Esc` — снять выделение; `Ctrl+A` — все.
- Клавиатура: стрелки перемещают фокус по сетке, `Enter` — открыть, `Space` — выделить, `Delete` — убрать из списка (с подтверждением).

## 4. Вид «Список» (таблица)

- Колонки по умолчанию: Обложка (36×48) · Название · Год · Разработчик · Жанры · Платформа · Статус · Моя оценка · Metacritic · Часы · Добавлено. В списках/сериях первая колонка — №.
- Колонки настраиваются: ПКМ по заголовку — чекбоксы; перетаскивание заголовков меняет порядок; ширина тянется; всё запоминается на scope.
- Клик по заголовку сортирует (повторный — направление); текущая сортировка синхронизирована с dropdown из заголовка экрана.
- Строка: hover-подсветка, те же контекстное меню и быстрые действия (иконки появляются справа при hover).
- Плотность строк: обычная 48 px / компактная 36 px (настройка).
- Группировка (опция в меню сортировки): без / по статусу / по году / по жанру / по платформе / по серии / по разработчику — группы со заголовками и счётчиками, сворачиваемые. В сетке группировка тоже работает (секции).

## 5. Сортировка

Поля: `title` (по `sort_title`), `release_date`, `added_at`, `started_at`, `finished_at`, `last_activity_at`, `rating` (моя), `metacritic_score`, `playtime_minutes`, `hltb_main_min`, `priority`, `times_completed`, `position` (только в списках с `sort_mode = manual` и в сериях — по умолчанию), `random`.

- Вторичный ключ всегда `sort_title ASC`, затем `id` — порядок детерминирован.
- `NULL` значения — в конце при любом направлении.
- `random` — seed хранится в состоянии экрана; кнопка «перемешать» меняет seed; при возврате «назад» порядок сохраняется (seed в состоянии маршрута).
- Направление по умолчанию: даты и числа — DESC, название — ASC.
- В ручных списках/сериях сортировка по умолчанию — `position ASC`; при выборе другой сортировки drag-n-drop отключается и показывается подсказка «Вернитесь к ручному порядку, чтобы перетаскивать».

## 6. Кольцо прогресса

Компонент `ProgressRing` — SVG-кольцо с анимацией заполнения (0 → значение за 900 мс, easing из дизайн-системы, при `prefers-reduced-motion` — мгновенно), внутри — процент; рядом текст `done / total` и подпись «пройдено». Размеры: 56 px (заголовок), 40 px (шапки карточек списков/серий/студий), 24 px (сайдбар, без текста внутри — tooltip).

Правила расчёта (`done / total`):

| Scope | Числитель `done` | Знаменатель `total` |
|---|---|---|
| Библиотека «все» | `status = completed` | все `user_game` кроме `wishlist` |
| Библиотека по статусу (напр. «Прохожу») | кольцо не показывается; вместо него — счётчик и суммарные часы | — |
| Пользовательский список | игры списка со `status = completed` | все игры списка (игры без `user_game` считаются не пройденными) |
| Серия | игры серии со `status = completed` | все игры серии `category IN (main, remake, remaster, standalone_expansion)`; DLC не считаются (переключатель «учитывать DLC» в меню) |
| Студия / издатель | пройденные игры компании | игры компании, **которые есть в моей библиотеке** (`user_game` существует, не wishlist); tooltip показывает второе число «из N в каталоге» |
| Профиль | как «Библиотека все» + отдельные кольца: mastered / всего пройденных; часы за год / цель года (если задана) | |

Цвет кольца — акцент дизайн-системы; при 100 % — цвет «успех» и короткая анимация «вспышка/конфетти» один раз за сессию.

## 7. Панель фильтров

Порядок секций и типы контролов (все секции сворачиваемые, у активной — счётчик выбранного):

| # | Секция | Контрол | Поле БД |
|---|---|---|---|
| 1 | Поиск по названию | текст (мгновенно) | `games.title`, `alt_titles_json`, `sort_title` |
| 2 | Статус | чипы мультивыбор: Хочу · Бэклог · Играю · Пройдена · Отложена · Брошена · Поиграл | `user_game.status` |
| 3 | Флаги | тумблеры: Избранное · 100 % · Есть отзыв · Без оценки · С приоритетом | `is_favorite`, `is_mastered`, `review`, `rating IS NULL`, `priority > 0` |
| 4 | Год выпуска | двойной слайдер + два поля (мин/макс от данных); чекбокс «включая без даты» | `release_year` |
| 5 | Жанры | чипы мультивыбор с поиском; переключатель «любой из / все» (OR/AND) | `game_genres` |
| 6 | Платформа (релиз) | чипы, сгруппированы по семейству | `game_platforms` |
| 7 | Моя платформа | чипы | `user_game.platform_id` |
| 8 | Режимы | чипы | `game_modes` |
| 9 | Разработчик | комбобокс с поиском, мультивыбор | `game_companies role=developer` |
| 10 | Издатель | комбобокс с поиском, мультивыбор | `game_companies role=publisher` |
| 11 | Серия | комбобокс, мультивыбор; чекбокс «не в серии» | `series_games` |
| 12 | Страна студии | комбобокс с флагами | `companies.country_code` (через developer) |
| 13 | Metacritic | двойной слайдер 0–100; чекбокс «без оценки» | `metacritic_score` |
| 14 | Моя оценка | двойной слайдер 1–10 (показ звёздами) | `user_game.rating` |
| 15 | Часы наиграно | двойной слайдер с бакетами (0 · 1 · 5 · 10 · 20 · 50 · 100 · 200+) | `playtime_minutes` |
| 16 | Время прохождения (HLTB) | бакеты: до 5 ч · 5–15 · 15–40 · 40+ · неизвестно | `hltb_main_min` |
| 17 | Категория | чипы: Основная · DLC · Дополнение · Ремейк · Ремастер · … | `category` |
| 18 | Статус релиза | чипы: Вышла · Ранний доступ · Анонс | `release_status` |
| 19 | Владение | чипы: Цифра · Физическая · Подписка · Пиратка · Нет · Продана | `ownership` |
| 20 | Теги | чипы | `game_tags` |
| 21 | Списки | комбобокс «в списке …» / «не в списке …» | `list_items` |
| 22 | Даты | добавлено / начал / закончил — пресеты (неделя, месяц, год, кастом) | `added_at`, `started_at`, `finished_at` |

Правила:
- Между секциями — **AND**; внутри секции — **OR** (кроме жанров/тегов, где есть переключатель AND).
- Каждый чип показывает счётчик совпадений **с учётом остальных активных фильтров** (фасетный поиск, как в GOG). Счётчики пересчитываются одним запросом на секцию, дебаунс 150 мс.
- Кнопка внизу панели «Показать N игр» (на узких экранах панель — шторка) и «Сбросить всё».
- Активные фильтры дублируются чипами над сеткой с крестиками (удаление по одному).
- Панель адаптируется к scope: в серии скрыта секция «Серия», в студии — «Разработчик», на странице издателя — «Издатель»; в каталоге модерации нет секций по пользовательским данным.

## 8. Производительность и данные

- Запрос к БД строится на backend по `filters_json` (билдер с параметризацией; никакой конкатенации пользовательских строк). Возвращает **плоские строки карточек** (см. запрос в документе 02 §5), лимит не нужен — библиотека одного пользователя редко превышает 2–3 тыс. игр; но список рендерится **виртуализированно** (окно + overscan 2 ряда).
- Загрузка в два шага: сначала список id + минимальные поля (для мгновенного счётчика и колец), затем строки карточек. На практике одним запросом ≤ 50 мс — допускается один запрос.
- Изображения обложек — ленивая загрузка (`loading="lazy"`), плейсхолдер `dominant_color`, плавное появление (fade 200 мс).
- Изменение фильтра → дебаунс 150 мс → запрос → **FLIP-анимация** перестановки карточек (оставшиеся карточки плавно переезжают, новые появляются fade+scale, удалённые исчезают). При > 300 карточках FLIP отключается, остаётся fade.
- Любая запись в БД инвалидирует кеш коллекций; открытый экран перезапрашивает данные без мерцания (сохраняет скролл).

## 9. Отличия по scope

| Scope | Особенности |
|---|---|
| Библиотека → «Все» | статус-фильтр доступен; кольцо; кнопка 🎲 |
| Библиотека → «Бэклог» / «Играю» / «Пройдено» / «Отложено» / «Брошено» / «Хочу» | предустановленный статус (нельзя снять, но можно добавить второй через панель); для «Бэклог» доп. сортировка по приоритету и группировка по приоритету; для «Пройдено» — группировка по году завершения по умолчанию |
| Пользовательский список | ручной порядок с drag-n-drop (в сетке и таблице), номер позиции, заметка к позиции (иконка 💬 на карточке, редактирование в попапе), кнопка «Добавить игры» (поиск-диалог с мультивыбором), шапка с обложкой/иконкой/цветом списка |
| Серия | порядок drag-n-drop (см. документ экрана серии); группировка по под-сериям; DLC показываются под родительской игрой (сгруппированы) с переключателем |
| Студия / издатель | вкладки «Игры» и «Серии»; кольцо считается по «моим» играм; фильтр роли (разработала / издала / портировала) |
| Результаты поиска | без панели фильтров, только сортировка; показываются и игры вне библиотеки (с кнопкой «Добавить в бэклог» на hover) |
| Каталог (модерация) | все игры каталога, включая не в библиотеке; вид «таблица» по умолчанию; колонка «Заполненность» (процент заполненных полей); быстрые действия — редактировать/удалить |

## 10. Пустые состояния и ошибки

- Нет игр вообще: иллюстрация + «Добавьте первую игру» → кнопка ведёт на страницу добавления.
- Фильтры дали ноль: «Ничего не найдено под эти фильтры» + кнопка «Сбросить фильтры» + предложение убрать самый ограничивающий фильтр (тот, отключение которого даёт больше всего результатов — считается тем же фасетным запросом).
- Ошибка запроса: inline-баннер с текстом ошибки и «Повторить»; лог в файл.

## 11. Критерии приёмки

1. Переключение сетка/список сохраняется после перезапуска для каждого scope отдельно.
2. Любая комбинация фильтров даёт результат ≤ 200 мс на базе из 2 000 игр (замер на референсном ноутбуке, SSD).
3. Кнопки «назад/вперёд» восстанавливают фильтры, сортировку, вид и позицию скролла.
4. Кольцо прогресса совпадает с ручным подсчётом по правилам §6 на тестовой базе.
5. Drag-n-drop в списке/серии сохраняет порядок в БД одной транзакцией и переживает перезапуск.
6. Все действия доступны с клавиатуры; фокус виден.
