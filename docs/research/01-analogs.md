# Исследование аналогов (Backloggd, Letterboxd, Shikimori, Playnite, GOG Galaxy, HLTB и др.)

> Материал подготовлен исследовательским агентом 2026-09-07. Используется как источник требований для ТЗ.
> Ссылки — на состояние продуктов на 2025–2026 гг.

## A) Статусы игры: сводка и рекомендация

| Продукт | Основные статусы | Вторичные флаги / поля |
|---|---|---|
| **Backloggd** ([about](https://backloggd.com/about/), [changelog](https://backloggd.com/changelog/)) | Четыре независимых тумблера **Backlog / Playing / Played / Wishlist** (можно одновременно). У Played подстатус: **Played, Completed, Mastered, Retired, Shelved, Abandoned** | Несколько *логов* (прохождений) на игру, у каждого своя оценка (5★ с половинками), платформа, отзыв, даты «started/finished», **Time to Finish / Time to Master**, чекбокс Mastered на уровне лога (1.14). Ownership: Physical / Digital / Sold-Lost / Subscription (+сервис). Medium (как играл, вкл. «Watched»). Три поля платформ: релизная, «played on», «library platform» |
| **Letterboxd** ([FAQ](https://letterboxd.com/about/faq/)) | **Watched** (глаз) / **Watchlist** / **Like** (сердце) | Diary-запись: дата, флаг **rewatch**, теги, 0.5–5★, отзыв. Favorites «top four» в профиле |
| **Shikimori** ([список](https://shikimori.io/d1cret/list/anime)) | **Запланировано / Смотрю / Пересматриваю / Просмотрено / Отложено / Брошено** | Оценка 1–10 со словесной меткой («8.59 — Отлично»), счётчик эпизодов, число пересмотров, текстовая заметка |
| **Playnite** ([Game model](https://api.playnite.link/docs/api/Playnite.SDK.Models.Game.html)) | Настраиваемые Completion Statuses (по умолчанию Not Played / Played / Beaten / Completed / Playing / Abandoned / On Hold / Plan to Play) | Favorite, Hidden, Installed; правила авто-статуса «для импортированных без наигранного» и «при первом запуске»; UserScore/CriticScore/CommunityScore |
| **GOG Galaxy 2.0** | Статусов нет — пользователи заводят теги «Beaten», «Backlog», «Trash» | Installed, персональный ★-рейтинг, закладки-виды |
| **HowLongToBeat** | **Playing / Backlog / Replays / Custom / Completed / Retired** | Время по категориям Main / Main+Extras / Completionist (+Co-op/Vs), платформа, оценка |
| **Grouvee** | Полки **Playing / Backlog / Wish List / Played** + произвольные полки | Платформа, 5★, статус-апдейты в процессе |
| **Infinite Backlog** ([1.10](https://medium.com/@infinitebacklog/1-10-play-log-play-records-6823e51073d8)) | **played / beaten / completed / dropped / shelved**; play record «beaten/completed» сам ставит статус и дату | Коллекция: дата и место покупки, подписка, «одолжил кому / вернули» |
| **Completionator** | Владение + физ. состояние, completion + несколько типов длительности | Wishlist с приоритетом, сложность, теги |
| **Backloggr (iOS)** | Playing / Completed / Backlogged / **Mastered** / Wishlisted + **Replaying / Shelved** | Авто-Mastered при 100% ачивок, авто-Completed по сюжету; оценка 1–10 с цветным бейджем |
| **Backlogged (iOS)** | playing / completed / **paused** / dropped / saved for later | «resume notes», сессии, журнал |
| **Steam / Xbox / Epic** | Play state: unplayed / played / installed; Xbox: Installed / Ready to install / Owned / Game Pass / Cloud | Коллекции, playtime-бакеты (<1ч, 1–10ч, 10+) |
| **Trakt / Simkl / MAL** | Watching / Plan / Completed / On Hold / Dropped (+Rewatching) | MAL: priority, rewatch value, теги, даты start/finish |
| **Кинопоиск** | Буду смотреть / Просмотрено / Любимые + произвольные папки | Оценка 1–10, «Друзья оценили» на карточке |

**Рекомендуемый набор для нашего приложения** — один взаимоисключающий основной статус + флаги на уровне прохождения:

1. **Хочу** (wishlist, не владею)
2. **В бэклоге** (владею / доступна, не начата)
3. **Играю**
4. **Пройдена**
5. **Отложена** (вернусь — Shelved/On Hold)
6. **Брошена** (не вернусь — Abandoned/Dropped)
7. **Поиграл** (без цели «пройти»: мультиплеер, песочницы, роглайки; у Backloggd в реальном профиле это 14 % всех Played)

Флаги/поля прохождения (не статусы): **100 % / платина**, **повтор (replay)**, платформа прохождения, даты начала/окончания, часы, оценка, заметка. Владение отдельно: физ / цифра / подписка (сервис) / нет / продана.

Обоснование: взаимоисключающий статус даёт корректные проценты в кольцах прогресса и статистике (в Backloggd одновременные тумблеры вынуждают отдельно объяснять «Played 68 % + Backlog 30 %»). «Mastered» как флаг, а не статус, — к этому пришёл сам Backloggd в 1.14 и Backloggr; иначе «Пройдена» и «100 %» двоятся в отчётах. Разделение «Отложена/Брошена» есть во всех зрелых трекерах и нужно для «вернуться к отложенным».

## B) Поля фильтрации и сортировки

Ориентир — Playnite (31 поле сортировки и 26 группировки: [SortOrder](https://api.playnite.link/docs/api/Playnite.SDK.Models.SortOrder.html), [GroupableField](https://api.playnite.link/docs/api/Playnite.SDK.Models.GroupableField.html)) и браузер Backloggd ([lib/popular](https://backloggd.com/games/lib/popular/)).

**Фильтры по метаданным игры**
- Год выпуска / десятилетие; «Вышла / Анонс»
- Жанр, тема/теги IGDB, режим (single/co-op/multiplayer)
- Платформа (релизная), разработчик, издатель, серия
- Категория: Main / DLC / Expansion / Standalone / Remake / Remaster / Port / Bundle / Mod (Backloggd 12 категорий; «Base game vs Extra» влияет на всю статистику)
- Рейтинг сообщества/критиков (слайдер), возрастной рейтинг
- Время прохождения HLTB (диапазон: «до 5 ч», «5–15», «15–40», «40+») — в будущем
- Популярность/«нишевость» (слайдер Popular↔Niche у Backloggd)

**Фильтры по пользовательским данным**
- Статус, флаги 100 %/replay, избранное, скрытые
- Моя оценка (диапазон), «без оценки», есть отзыв/заметка
- Владение/носитель, сервис подписки, платформа прохождения
- Пользовательские теги
- Дата добавления, дата начала, дата завершения, последняя активность
- Наигранные часы (бакеты как в Steam), число прохождений
- Входит / не входит в список X

**Сортировки**: название (с «sorting name», игнор артиклей), дата выхода, дата добавления, дата начала, дата завершения, последняя активность, моя оценка, средняя оценка, часы, HLTB-время, популярность, число прохождений, **случайно**.

**Группировка** (Explorer-панель Playnite): платформа / жанр / год / статус / серия / разработчик / оценка.

Правила: внутри одного поля — OR, между полями — AND (Steam делает только AND и это главная жалоба пользователей); опция «AND внутри поля» как у Playnite `UseAndFilteringStyle`. Обязательно **сохранённые пресеты фильтров** с показом как чипы над сеткой (Playnite filter presets, GOG bookmarks, Steam dynamic collections) и счётчик совпадений рядом с фильтром (GOG).

## C) Профиль: статистика, достижения, уровни

**Что показывать (по приоритету)**
1. Шапка: N игр, N часов, «с N года», stacked-bar по статусам с процентами (Shikimori/MAL) — плюс наши кольца.
2. Часы: всего, среднее на игру («7 709 ч над 257 играми, 30 ч/игра» — Backloggd), топ-6 по часам / по прохождениям / по дням в журнале.
3. Гистограмма оценок 1–10 (Letterboxd «ratings spread», MAL mean score).
4. По годам: пройдено за год (табы 2016–2026 как у Backloggd), по годам/декадам выпуска и «highest rated decades» (Letterboxd).
5. Жанры и платформы — бары с hover «% и средняя оценка» (Backloggd); лучшие студии (средняя оценка + сколько сыграно: «FromSoftware 4.7, 16 игр»).
6. Пирог владения; разбивка Main/DLC/Remake.
7. Активность: heatmap по дням (Simkl), стрики «N недель подряд с ≥1 игрой», «дней с 2+ сессиями» (Letterboxd), сессии по дням недели/часам (Trakt).
8. Вехи: 50-я, 100-я пройденная игра с датами (Letterboxd milestones).
9. Годовой recap: первая/последняя игра года, пиковая неделя, «играл 320 дней из 365» (Backloggd 2025), топ-5 игр, топ-жанр, сравнение с прошлым годом.
10. «Здоровье бэклога»: добавлено vs пройдено за год (челлендж Infinite Backlog), «бэклог займёт N часов по HLTB».

**Достижения (уровни как в Shikimori: 15/50/100/… с ироничными названиями)**

| # | Достижение | Условие |
|---|---|---|
| 1 | Первая кровь | Первая игра со статусом «Пройдена» |
| 2 | Минус бэклог | Пройдено 10 / 50 / 100 / 250 / 500 / 1000 игр |
| 3 | Платиновый | 100 % в 1 / 5 / 25 / 100 играх |
| 4 | Марафонец | 100 / 500 / 2000 / 10 000 часов в журнале |
| 5 | Стрик | 7 / 30 / 100 дней подряд с сессией |
| 6 | Ретроман | 10 / 30 пройденных игр, выпущенных до 2000 г. |
| 7 | Серийный | Пройти 100 % игр серии — по одному бейджу на серию |
| 8 | Жанровый гурман | 5 / 15 / 40 пройденных в жанре X (отдельная ачивка на жанр, ур. 1–4) |
| 9 | Годовой баланс | За календарный год пройдено ≥ добавлено в бэклог |
| 10 | Разгребатель | Пройти игру, пролежавшую в бэклоге > 2 лет |
| 11 | Скороход | Пройти 5 игр быстрее HLTB Main Story |
| 12 | Мультиплатформенник | Прохождения на 3 / 6 / 10 разных платформах |
| 13 | Критик | 10 / 50 / 200 отзывов или заметок |
| 14 | Куратор | 5 списков или один список из 50+ игр |
| 15 | Честный судья | 100 оценок, при этом использованы ≥ 6 разных значений шкалы |

**Формула уровня**: XP = 10·пройдено + 15·(100 %) + 1·час (кап 100 XP на игру, как кап 200 XP/игра у [PlayTracker](https://playtracker.net/guide/leveling_up/)) + 3·отзыв + 20·каждый уровень достижения. Уровень линейный: каждые 500 XP. К уровням привязать титулы («Эстет», «Точка невозврата» — стиль Shikimori) и косметику профиля (рамка, фон).

## E) Заметки по UX: навигация и страница игры

**Страница игры (лучшая — Backloggd, [пример](https://backloggd.com/games/elden-ring/))**: hero-скриншот на всю ширину → обложка слева, справа «Название · год», разработчик/издатель → описание → строка жанров + платформ → гистограмма оценок со средней → счётчики → средние времена → табы **Reviews / Related / DLC / Editions / Series**. Издания (GOTY, Deluxe) склеены в родительскую игру — стоит повторить. Пользовательский блок (статус, оценка, время, даты, заметка) держать sticky рядом с обложкой.

**Shikimori**: инфоблок как key-value таблица, оценка с текстовой меткой («Отлично»), «Хронология/франшиза» деревом, распределение по статусам.

**Playnite (desktop)**: три вида — Details (компактный список + правая панель деталей), Grid (обложки, hover-info), List (таблица, колонки настраиваются правым кликом по заголовку). Explorer-панель слева = мгновенная группировка по любому полю; горячие клавиши Ctrl+G фильтры, Ctrl+E Explorer, F3 правка. Сохранённые пресеты фильтров всплывают в верхней панели.

**GOG Galaxy 2.0**: сайдбар Recent / Installed / All + закладки-виды + теги; карточка грида показывает название, личный рейтинг и *одно* настраиваемое доп. поле — идея для переключателя «что показывать на карточке». Рядом с фильтром — число совпадений. Кнопка «назад» внутри библиотеки.

**Steam**: слайдер размера грида; «скрыть игру» вместо удаления; динамические коллекции. Антипаттерн — только AND между тегами.

**Letterboxd**: минимальная модалка лога в один клик; редактор ранжированного списка с вводом номера позиции и «Sort by» перед сохранением; год-табы и «all-time» в статистике.

**Xbox app 2025**: кросс-девайсный «Most Recent», фильтры-чипы. **Кинопоиск**: счётчик в шапке профиля, «скрытый профиль».

**Навигация в целом**: у веб-аналогов — верхнее меню + табы профиля с счётчиками; у десктопных (Playnite, GOG, Steam) — левый сайдбар с «Recent / All» и коллекциями. Наша комбинация «сайдбар + хлебные крошки + назад/вперёд + панель фильтров справа» соответствует GOG; добавить Ctrl+K и сохранённые пресеты как чипы.
