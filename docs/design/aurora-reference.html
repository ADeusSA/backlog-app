Что демонстрирует файл

  • Сцена: фон #0B0D14 и два дрейфующих свечения (bloom) с ограниченной насыщенностью.
  • Стекло только на рельсе, панели фильтров, блоке «Сейчас играю» и панели пользователя.
  • Карточки: полупрозрачная заливка без blur, подъём и акцентное кольцо на hover, быстрые действия снизу.
  • Один акцент (фиолетовый) для «выбрано», бирюзовый только для «пройдено» и оценок.

Как пользоваться

  • Переключайте «Библиотека / Страница игры», сетку и список, чипы фильтров, сегмент статуса.
  • Наводите на карточки и обложки серии.
  • Числа, размеры и правила — в docs/04-design-system.md; при расхождении приоритет у документа.
